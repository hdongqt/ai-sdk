# 🚀 AI Vip Pro - Gemini Assistant

Chào mừng bạn đến với **AI Vip Pro**, một trợ lý AI thông minh được phát triển bởi **Dong Dev**. Dự án này sử dụng sức mạnh của **Vercel AI SDK** kết hợp với các mô hình ngôn ngữ tiên tiến từ **Groq** và **Google**.

## ✨ Tính năng nổi bật

- **Trò chuyện thông minh:** Sử dụng model `llama-3.3-70b-versatile` qua Groq cho tốc độ phản hồi cực nhanh và chính xác.
- **Giao diện hiện đại:** UI được thiết kế tối giản, sang trọng với Tailwind CSS, hỗ trợ Dark Mode và hiệu ứng mượt mà.
- **Phong cách "Vip Pro":** AI được cấu hình với tính cách trẻ trung, lễ phép

## 🛠 Công nghệ sử dụng

- **Framework:** [Next.js 15+](https://nextjs.org/) (App Router)
- **AI Integration:** [Vercel AI SDK](https://sdk.ai.dev/)
- **LLM Provider:** [Groq](https://groq.com/) & [Google Gemini](https://ai.google.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons & Fonts:** Geist Font, Lucide React (nếu có)

## 🚀 Bắt đầu ngay

### 1. Clone dự án
```bash
git clone <your-repo-url>
cd ai-sdk
```

### 2. Cài đặt dependencies
```bash
npm install
```

### 3. Cấu hình biến môi trường
Tạo file `.env.local` và thêm các key sau:
```env
GROQ_API_KEY=your_groq_api_key
```

### 4. Chạy môi trường Development
```bash
npm run dev
```
Mở [http://localhost:3000](http://localhost:3000) để trải nghiệm.
